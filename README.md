# Project 04 - Microsoft Entra ID Employee lifecycle Management

## Project Overview

This project demonstrates a complete employee lifecycle in Microsoft Entra ID, Including onboarding, identity management, role assignments, password management, and employess offboarding.

the objectives was to simulate the responsibilities of an IT Support Specialist or Junior Systems Administrator in a real enterprise environment.

---

## Business Scenerio

Popes Manufacturing hired three new employees.

As the IT Support Specialist, I was responsible for:

- Creating user accounts
- Assigning departments
- adding users to security groups
- Assigning administrative roles
- Performing password resets
- Offboarding a terminated employee
- Restoring access after rehire

# Tasks Performed

## 1. Created New Users

Created three employees:

- Emily Carter (Human Resources)
- Marcus Johnson (Sales)
- Olivia Martinez (IT Support)

Each account was configured with:

- Department
- Job Title
- Password Change at Next Sign-in

---

## 2. Department Security Groups

Assigned employee to existing security groups:

- HR
- Sales
- IT Support

This demonstrates department-based access management.

---

## 3. Role-Based Access Control

Assigned the User Administrator role to the IT Support Technician.

This follows Microsoft's Principle of Least Privilege by avoiding unnecessary Administrator permissions.

---

## 4. Password Management

Assigned a secure password reset for Emily Carter.

required password change during the next sign-in.

---

## 5. Employee Offboarding

Disabled Marcus Johnson's account and verified continued access.

---

## 6. Employee Rehire

Re-enabled Marcus Johnson's account and verfied continued access.

# Lessons Learned

This project reinforced the importance of properly managing identities throughout the emplotee lifecycle.

Using security groups and RBAC simplifies administration while improving security by ensuring users receive only the permissions required for the job responsibilities.
